# RK Automobile

**RK Automobile** is a clean and responsive web application built for automobile services.  
It allows users to browse, search, and filter vehicles easily. The interface is designed to be user-friendly and works smoothly on both desktop and mobile devices.

## Features
- Browse all available vehicles
- Search and filter vehicles based on type, brand, or other criteria
- Responsive design for mobile and desktop
- Smooth navigation between pages

## Technologies Used
- **React** for building UI components
- **Vite** as the project build tool
- **TailwindCSS** for styling
- **JavaScript** as the programming language
